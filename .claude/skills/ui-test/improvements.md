# ui-test — improvements

Append one line whenever this skill misled you or was silent about a trap that then bit you.
- **Two assertions that look like product defects and are really test bugs, both hit in one run.** (1) `document.querySelector(".pages")` is the wrong element on this site: pages NEST, so several `.pages` boxes exist and the first is the app shell's — 900px tall and not scrollable — while the real scroller is deeper. Never name a scroller by selector; pick the element with the largest `scrollHeight - clientHeight`. (2) A row that lands inside a COLLAPSED fold is genuinely absent from `innerText`, and `ext/AITask`'s `fold()` does not even build its body until clicked — assert on the fold's own visible label ("Proposed — N not started") instead. Both first reported as FAIL against working code. (reload-rethink, 2026-09-22)
- **A third assertion that looked like a product defect and was a stderr problem.** A CLI warning written with `console.warn` goes to stderr, and `execFileSync(..., {encoding:"utf8"})` returns ONLY stdout — so the assertion read an empty string and reported FAIL against a warning that was printing perfectly. Use `spawnSync` and join `stdout + stderr` whenever a test asserts on what a command SAID. Three times in one run the first failure was the test, not the code: before reporting a FAIL, re-read the assertion against what the thing actually does. (reload-rethink D7, 2026-09-22)
