Read the readme chain at /framework/design/ (root → design), then its children's readmes for
the part you're doing: layout, color, navigation, content, ui. Each links its own
questions.md, which `review` reads.

Overview: the order of the job is what it is → where it lives (navigation) → how big it is
(layout) → what it says (content) → what the reader presses (ui, carried by color). The two
tests for every element: self-evident, and necessary. A page's inbox (coordination notes) is a
Servex fact, not a design one — see /framework/ai/inboxes/.
