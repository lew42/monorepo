name: navigation
description: The path — how links look, persistent or switching, transitions, back and reload. Invoke before building tabs, a rail, a sidebar, a sheet, a modal or a full-screen view.
---

Read the readme chain at /framework/design/navigation/ (root → design → navigation), then its
questions.md.

Overview: route everything — any view a click reaches has its own URL; a rail or sidebar sits
beside a centred main column and stays still while its work area updates; a sheet or modal has
its own URL and returns to the same place on close; a selected item opens in its own column,
never by expanding in place.
