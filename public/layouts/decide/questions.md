1. How much room is there? Work it out top down. The site's nav, a rail or a table of contents are already known before this page draws, so what is left is known too. A phone always gets one column; that is the floor, not the design. Usual answers: A phone: one column, always; One reading column, about 40em; A wide main beside a sidebar; Most of a 3440 screen. Answer for this page only, in a few plain sentences, and name the answer you pick.
2. How much content is there? Match the layout to the amount. A little content wants a small, tight box; a lot of content wants structure a reader can steer by, and not one endless column. Usual answers: A little: a preview card, a few lines; About one screen; A lot: many sections, wants tabs or a left nav. Answer for this page only, in a few plain sentences, and name the answer you pick.
3. Is it outlined yet? A layout chosen before you know what the page says is a guess. Write the outline first: the sections in order, which demos, which tabs. Then the layout usually picks itself. Usual answers: Yes: sections, order and demos are written down; No: write the outline now, then come back. Answer for this page only, in a few plain sentences, and name the answer you pick.
4. How will the content fill the width? On a wide screen the answer is nearly always to fill it, so the question is how. Columns side by side work best when their content is roughly equal in height. When one column is naturally short, like a title, centring it vertically lets it carry weight instead of leaving a hole. Usual answers: Columns side by side, equal in height; A short title column, centred, beside the rest; A wall of cards; A nav column beside a centred main; Tabs or a left nav for a lot; One small box, and the space left on purpose. Answer for this page only, in a few plain sentences, and name the answer you pick.
5. Which approved layout fits? Start from a layout the owner has already approved; it has been proven at 400 and at 3440. If none fits, build the new one as a proposal and say it is new. Each layout the owner approves makes the next choice more certain. Usual answers: Standard: one column; Split: two columns, any proportion; Columns: three or more; Tile wall; Rail + content; Docs three-region; None fits: a proposal. Answer for this page only, in a few plain sentences, and name the answer you pick.
