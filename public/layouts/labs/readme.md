# Labs — six shape experiments that led to the ids above

**What.** Six places where one arrangement got built and played with before it earned an id
at [`/layouts/`](/layouts/): an app shell (`shells/`), what a click does to your screen
(`screens/`), a band cut into columns (`sections/`), a blog rendered eight ways at 3440
(`blogx/`), a magazine page (`mag/`), and a screen cut into regions (`decks/`).

**Use.** Open [/layouts/labs/](/layouts/labs/) and click any card — each lab stands alone,
with its own readme and doc.

**Watch out.** These six moved here from `/imagine/` on 2026-09-18
(`ai/2026-09-18/imagine-move-3/`, following
[the imagine-integration proposal](/framework/ai/2026-09-17/imagine-integration/proposal.md)).
Every old `/imagine/<name>/` address still answers — a one-line stub page points back here —
because production is static and there is no server-side redirect. A seventh realm,
`/imagine/layouts/` (the numbered `N.name` lab that gave `/layouts/` its ids), was deleted
outright rather than moved here: its own readme already conceded `/layouts/` owned the
names, and every one of its eighteen arrangements is mapped onto an id in
[`/layouts/doc/decisions.md`](/layouts/doc/decisions/).
