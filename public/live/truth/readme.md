# /live/truth/ — how true the session record is, counted by code

The page draws `truth.jsonl`; each line is one run of `node Server/Truth.mjs --write` (one object: `{"truth":{at, label?, all, week, twins, flat}}`). `all` and `week` (last 7 local days by the session's folder day) each hold: `sessions` (one per session id, `SessionFolders.homes`), `with_log` (record with assign/log/agent lines), `tag_only` (a session.jsonl holding only digest tags), `transcript_only` (only index.json/cache.jsonl; with_log + tag_only + transcript_only = sessions), `with_tasks`, `no_tasks` (= needs review; `with_tasks + no_tasks = sessions`, the script refuses to write if not), `complete` (score 1, of those with tasks), `done_tasks`, `unproven` (`Task.proof_problem`), `no_commit` (no `commit` line in the session's record or any task log under it), `prompts_unfiled` / `sessions_unfiled` (owner `Prompt` lines in sessions with no task). `twins` and `flat` come from `SessionConsolidate.check`; `folders` ({total, no_session_file, empty}) counts every date-level folder, including those that hold no session at all, and is not part of the denominator. The 1,410 twins in the first brief were folded before the first run; the check has found none since.

- **Writer:** `Server/Truth.mjs` (test `Server/Truth.test.mjs`), run daily by `TaskLoop.truth_daily()` in Servex (needs a Servex restart to start; done today = the last line's `at` is today). By hand: `node Server/Truth.mjs --write [--label "..."] [--root <repo>]`.
- **Reader:** `page.js` (`TruthLog extends JSONL`, streamed live).
- **Counts use the real classes:** `SessionFolders.homes()`, `Task.replay`/`tally()`/`completion_score()`, as `Server/session-query.mjs --report` does. They differ from a sample of the costliest sessions because they cover every session id, most of which are transcript-only. The first baseline line wrongly counted only records with a log (328 of 11,861); the second line (label "corrected") fixes it.
- The first line is the baseline, measured before the truth-job fixes merged.
