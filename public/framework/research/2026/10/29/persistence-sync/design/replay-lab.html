Replay Lab

Do something below, then press Reload. Every action is saved two ways at once: as the changes it made and as the method call. Reload rebuilds the page from each log, so you can see what each one brings back and what it does a second time.

Saved as changes

On reload: assign the values. No method runs.

Saved as calls

On reload: run each method again.

What the examples add up to

  1. Save the changes by default. Reload assigns values, so nothing runs twice and old history keeps its meaning.
  2. The screen follows the values. A task that is running looks running, after a click, after another tab's change and after a reload. No method has to run for that.
  3. Outside effects run once, where someone acted (spawn an agent, ask an AI), and their result is saved as a value (agent_id, the summary text).
  4. Save what the person meant. A visibility button means "hide it", so save visible: false, not toggle(). A +1 button means "add one", so the call must reach the server, which runs it and saves the result.
