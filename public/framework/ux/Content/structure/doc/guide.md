# Which piece when

The only test: what is the best way to present **this** information? These are examples, not rules: no fixed count, no fixed depth.

| For example, you have… | Often reads best as |
|---|---|
| One big idea, a place to go | a large **icon card** |
| A few related things | a **section**: a title over icon cards |
| A few destinations to label | a **section** with a **background** |
| Things inside things | an **outline** |
| A reason, a caveat | one sentence under the picture |

- **Hierarchy comes mostly from typography:** H1, H2, H3, and section titles that say what each section is.
- **Background or not** is each block's first choice. A background brings padding; none brings none. Options to choose between often suit a background; a plain list of links usually doesn't.
- **An outline often beats a paragraph.** "First… then… also…" usually wants to be a nested list.
