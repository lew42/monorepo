# Which piece when

| You have… | Use | Background? |
|---|---|---|
| One big idea, a place to go | **Icon card**, weight 3 | its own |
| 3–5 related things | **Section**: a title over icon cards | no |
| 3 destinations to label | **Section** with a **background** | yes, so padded |
| Things inside things | **Outline**: a nested list | no |
| A reason, a caveat | one sentence under the picture | no |

- **Background or not** is the first choice. A background brings padding; no background brings none.
- **Box what is a choice**, leave the rest bare. One level of background is usually enough.
- **Heavier first.** Cards sort by weight; a weight-3 card is the one the eye should land on.
- **A list beats a paragraph.** If you are writing "first… then… also…", it is an outline.
