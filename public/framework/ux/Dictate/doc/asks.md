# Transcription asks, merged (2026-10-12)

What the owner asked about the voice pipeline (Whisper, clean transcript, structure, refined prompt, cards on the session page, phone use), repeats folded together. Open first, most-asked first. Generated by `ai/2026-10-12/asks-transcription/gen.mjs` from 78 tagged prompts (578 candidates; scripts reused from [asks-by-module](/framework/ai/2026-10-12/asks-by-module/STATE.md)). Status was checked against readmes, role tables and file listings, not every line of code. Sources are the first 8 characters of a session id. Only 45 of 83 Haiku quotes were found verbatim, so counts are a floor.

Walk through it yourself: [try-it.md](try-it.md).
