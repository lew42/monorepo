# Text

The element the kit's tree starts from: `h1`–`h4`, a paragraph, a list, a link, and the
flow rhythm between them. No class, no page CSS — `framework.css` already does the whole
job (see [`styles/elements/text/`](/framework/styles/elements/text/) for the full inline
reference: `h5`/`h6`, emphasis, semantic tags, blockquote, `hr`).

Code: `ui/text/page.js`. Listed first in the [UI library](/framework/ui/)'s Elements band
([`ui/page.js`](/framework/ui/page.js) `BANDS`).
