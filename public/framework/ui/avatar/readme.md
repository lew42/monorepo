# avatar

A circle, sized by a token, that holds initials or a photo — and stacks into a ring of overlapping circles. No `ui.avatar()` — copy the markup.

## Use

```js
span.c("ui-avatar", "ML");
span.c("ui-avatar accent", "AK");
```

## Watch out

- Size is the `--avatar` token, never a variant class — there is no `small`/`large` — [avatar.js](avatar.js)
