# badge

A small pill label — the class list is the whole component. No `ui.badge()` — copy the markup.

## Use

```js
span.c("ui-badge ui-pill h4 accent", "shipped");
```

## Watch out

- Four tones only (`accent`, `dark`, `outline`, plain) — the token set has one accent and no `--ok`/`--warn` for a "passing" green — [badge.js](badge.js)
