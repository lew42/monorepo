# System tab: what is here, and what is not

The AI page's **System** tab. Today this folder holds one thing:

- [`models/`](models/) — `models.json`, the model benchmark: house-rule tests per model and effort, cost, a performance score and a value ratio (generated 2026-10-02). It answers *which model for which job*; it does not map the AI systems.

The map of the AI systems lives elsewhere: [`../systems-map.md`](../systems-map.md) (where each system lives and how fresh its readme is), [`../readme.md`](../readme.md) ("Every system, one line each"), [`../doc/readme.md`](../doc/readme.md) (all docs by subsystem) and [`../concepts.js`](../concepts.js) / [`../overview.js`](../overview.js) (the System tab's text).

Open: the tab has no page for Servex agents, sessions or the page system. Until it does, the readme index above is the map.
