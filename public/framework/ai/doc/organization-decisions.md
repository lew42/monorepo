# Organization system: decisions (2026-10-12)

- **Heartbeat is a script, not a Servex change.** `Servex/Heartbeat.js` and `TaskLoop.js` watch open tasks every few minutes; an hourly systems wake is a different job. Alternative: add a timer in `Servex.js`. Rejected for now: it needs a restart and the brief says batch it; the script is the unit either way, so Servex can call `Systems.run()` later.
- **Report only, no fixes yet.** `heal()` exists on `System`, no subclass implements it. Orphans and broken links need judgment; add safe fixes one at a time.
- **System is isomorphic; subclasses are node-only.** The page imports the base without fs; the checks read files.
- **Navigation check is lenient**: a page counts as linked if any file in the parent dir mentions its folder name. Alternative: parse `children:`. Stricter later.
- **Known gap:** ReadmeSystem's first run found readmes over 100 lines; not fixed here.
- **Wake is a session cron** (hourly at :17, 2026-10-12): it dies with the session and after 7 days, so the mastermind re-arms it. Durable alternative: a Servex timer calling `Systems.run()` (needs a restart; next step).
- **Reply/content rules need one home (proposal, not applied).** CLAUDE.md ("Chat is the headline", "How to respond", "Replies are short titled lists") and `.claude/skills/content` both say how to format replies and disagree (skill: at most 3 headings, bold-title bullets; CLAUDE.md: `###` headings with icons, emoji bullets). Proposed: CLAUDE.md keeps the owner's rules; the content skill drops its "Helpful headings" paragraph and links to CLAUDE.md, keeping page-content advice. CLAUDE.md needs the owner; shared skills go through the system-architect. Put here because `page_add` wrote only empty lines to `systems/page.jsonl` (two blank parts, harmless).
- **Moved to `ext/System/` (2026-10-12, owner).** The System class is generic, not an AI thing, so it lives in an extension; `ai/systems/` keeps one-line shims for the old imports. Alternative: leave it under `ai/` (rejected: it is not AI-only). `ReadmeSystem`/`NavigationSystem` stay in `ext/System/` because they check the whole site, not one module. AI systems are individual instances beside their module (`system.js`). Future compositor (drag-drop wiring of system cards) is noted in `ext/System/doc/system.md`, not built.
