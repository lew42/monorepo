## The calls, made by the mastermind

- **`--size` is the one knob; there is no `--ui-size`.** A control's height, padding and font derive from `1em × var(--size, 1)` so that `.size-small` set ON A PANEL (a toolbar, a rail, a dense list) makes every control inside it compact, and nothing else changes. Default `--size` is 1 and the default control is exactly the base font size — **no change to default sizing**. `--size` is unitless and never a function of width.
- **One control grammar.** Every control — button, chip, select, input, textarea, tab, dropdown trigger, toolbar item, toggle — shares: one height at a given `--size` (line-height + the same vertical padding), the same horizontal padding, the same hairline border (`--line`), the same radius, the same focus ring, the same disabled look, the same hover and active. The nine accidental button families become one, with the real variants kept as words (`prim`, `ghost`, `danger`, `small` — read what exists; do not invent a fifth variant).
- **A little more compact than today** — the vertical padding comes down by roughly a quarter and the horizontal by a fifth; measure today's and land numbers, not adjectives. **Better borders**: a hairline that reads at 3440 (not 1px alpha that vanishes), consistent between light and dark, and the same on every control.
- **Minimal.** If a control needs a rule the grammar does not have, the grammar is wrong; fix the grammar. Aim for FEWER control rules in `framework.css` after than before — count them.
