# Page API for AIs: few universal tools, one simple model (mastermind brief)

**Owner (2026-10-12, dictated before bed):** finish the page basics: CRUD for subpages, how content is saved, and real-time AI interaction through the page system, so agents create content cards live through the tools. Not a tool per card kind: a few universal tools that take deltas (property name + value) that the model picks itself, so it needs to know the system (tool descriptions, or a skill). A simple model a human or an AI can understand: the properties, the data structures, how they flow, and which tool does what, under what name. "Keep it simple and straightforward so it's clear what needs to happen, which tool needs to be called, what things are called."
