# smoke-brief — the two-line brief that proves a minion still lands

Load the `minion` skill, then write a file called `hello.txt` in this same directory whose only
line is the words `minion landed`, and land.

Do not open a task, do not write to any `.jsonl`, and do not touch any other file. This brief
exists only to prove that the shrunk `minion` skill still reads as a minion's instructions.
