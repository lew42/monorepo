**Routed by servex-mastermind-opus:** one component on every surface: the mobile ✦ rail, the desktop right sidebar (the ☰ drawer's AI tab), and the AI 2 card sidebar. The old per-card assistant (Layers.js page-ai → `assistant-<card>`) and the model chooser retire, or fold into the pair. `/api/page-ai` feeds the same pair, so the owner's VS Code prompts appear and refine in the same chat.

**Rules:** no budget cap. Plan first and post it on the card. Build in small merges, and screenshot-check each one on every surface before the next. Wait for the 5-hour reset if the window is tight.
