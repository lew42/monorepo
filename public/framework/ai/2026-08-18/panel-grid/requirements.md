## Scenarios (grid) — each one a numbered step list, each verified at 4 widths

1. **Set `display: grid` on the root leaf** via the toolbar pop; put six swappable pieces of content in it (templates; `random` allowed). What tracks does the overlay draw (`display.js` `grid_layer`)? Is there any way in the UI to choose column count / `auto` / `three` / a template-areas shape? If not, that is finding #1 — say what `page.evaluate` word you had to set instead.
2. **Reconfigure the grid**: change column count / gap / a child's span or place (`live_axes` says grid children get both axes — the toolbar's alignment/place pop, `PLACE`). Which of these exist as gestures, which only as words in `properties.js`, which not at all?
3. **Grid vs split**: divide the root into two columns by edge click, then make the LEFT one a grid of four and the RIGHT one a grid of two. Resize the seam. Do both grids re-flow their tracks? At 400 does anything overflow?
4. **A card wall**: `auto` (count-itself) columns with six cards — at 400/800/1280/1920, how many columns, any overflow, any orphan row? Compare with the same six in `flex wrap` if the words exist (one png side by side is worth the table).
5. **Nested**: a grid cell that is itself split (edge click inside a grid child) — does the child grid/split honour the cell, or escape it (`min-width:0` / `min-height:0` tells)?
6. **fill vs hug** on a grid child (size.js) — does hug measure or declare (`--panel-hug`)? What happens to the track?
7. **`sow` a generated seed** (`space_dashboard`) that yields a grid word (roll until one does; log the seed) — screenshot at 1280 and 400; overflow or reflow?
8. **Scroll**: put a tall template in one grid cell — does the cell scroll, grow the row, or clip? Is a scrollbar changing the sibling column's width?

For each: works / broken / unclear · what you expected vs saw · the png · the step list. Where the UI is unreachable headlessly (a hover-only control), say so and use `page.evaluate` on the Panel tree instead — and log that the UI path was the miss.
