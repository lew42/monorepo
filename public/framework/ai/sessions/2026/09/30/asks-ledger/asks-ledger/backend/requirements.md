## Deliverables

1. **`public/framework/ai/asks/fold.js`** — pure, no imports from `/app.js`, runs in node and the browser. `ask_id(ask)` = `ask.id` if present, else a kebab slug of `ask.title` (lowercase, non-alphanumerics → `-`, trimmed, ≤ 48 chars). `fold_asks(lines)` takes parsed lines (`{"ask":{...}}` objects; skip anything else) and returns one object per id: the first line's fields, with each later line for the same id merged over it (latest status, `why`, `by`, `status_at` win), plus `history: [{status, why, by, at}]`. The existing 16 lines must fold unchanged (each becomes its own ask).
2. **`Servex/asks/stalled.js`** — ONE pure function `stalled(ask, owner_row, now)` returning `{stalled: bool, why: string}`. The rule, written in its header comment: an ask whose status is not `landed`/`dropped` is STALLED when its owner agent is `stopped` or `gone` (or has no row at all), or `dormant` with nothing queued to wake it, or has been silent (no turn, no task.jsonl line) for more than 2 hours. `owner_row` is what the tick assembles: the agent's registry row (`list_agents` shape: `state`, `last_at`, …) plus `last_task_line_at` and `queued` (count of messages waiting for it). Read `Servex/agents/Agents.js` and `Servex/agents/registry.js` to get the real field names; `dormant` is being added by another task today — accept the string, don't depend on code for it.
3. **`Servex/asks/Asks.js`** — class `Asks({servex, file})`. `file` defaults to `<repo>/public/framework/ai/asks.jsonl` resolved from `import.meta.url`. `read()` → `fold_asks` of the file. `mark(id, status, why, by)` appends ONE line `{"ask":{id, status, why, by, at}}` (local ISO time with offset, like `.claude/hooks/append.mjs` makes) and refuses an unknown id or status (routed building landed stalled dropped). Appends only; never rewrite the file. A `setInterval` of 60 s (`unref()`) runs `tick()`: for each open ask, build `owner_row` from `servex.agents` (registry rows, queue) and the owner's task dir's last `task.jsonl` line, call `stalled()`; mark `stalled` ONCE when it becomes stalled (not every tick — the folded status already says stalled); when a stalled ask's owner speaks again (working/idle with a fresh turn or task line) mark it back to `building`; when the owner's task.jsonl has a `landed_at` line, mark `landed`. Also wrap `servex.task_loop.close_task` at construction (keep the original's return) so closing a task whose agent owns an ask marks it landed. Every step a method (seams). No `Servex/Heartbeat.js` edits — another task owns it.

Skip it under the same env guard pattern tests use if one exists (e.g. `SERVEX_NO_ASKS`). That's the only Servex.js change.
