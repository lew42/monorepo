## The `ask` verb (defined here so the log viewer and the mastermind agree)

```json
{"ask": {"id": "layout-browser", "at": "<ISO>", "summary": "<one line>", "quote": "<the owner's sentence, verbatim>", "prompt": "<uuid of the user message in the session transcript>", "status": "open|building|landed", "tasks": ["<slug>"], "links": [{"url": "/…/", "label": "…"}]}}
```

Merged by `id`: a later line with the same id updates only the fields it names. `prompt` is the `uuid` of the user line in `~/.claude/projects/<cwd-slug>/<session_id>.jsonl`.
