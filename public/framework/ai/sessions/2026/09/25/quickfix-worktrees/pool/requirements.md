## Deliverables

1. `Servex/Pool.js`: a small class in house style (assign-based; see neighbouring Servex modules like `Usage.js`), wired from `Servex/Servex.js` (start, `tools()`, one route). Aim for about 200 lines.
   - Slots are made with the existing `Server/worktree-up.mjs <name>` and removed with `Server/worktree-down.mjs <name>`, run as child processes with `windowsHide: true` and **cwd = the MAIN repo** (`C:/Code/lew42/monorepo`; derive it with `git rev-parse --git-common-dir`, so slots branch from michael/dev even when this Servex runs from a worktree). Names `qf-1`, `qf-2`, `qf-3`, with the prefix from `SERVEX_POOL_PREFIX` (default `qf`, so a private Servex can use `qfp`).
   - State lives in `.worktree-pool.json` at the main repo root (override: `SERVEX_POOL_FILE`): `{ id, path, branch, url, port, state: "preparing"|"ready"|"taken", taken_by, taken_at, idle_since }`. It survives a Servex restart. On start: adopt the entries whose worktree still exists, then make sure one is ready.
   - **Ready means:** branched from michael/dev, its server answering, a page watcher on (`node Server/health-supervisor.mjs` started from the worktree root with `HEALTH_BASE=http://127.0.0.1:<port>`, hidden, pid recorded, killed on remove), and a git identity present (`git -C path config user.name` non-empty; else copy the main repo's).
   - The `take_worktree({})` MCP tool gives `{id, path, branch, url}` at once from a ready slot. Before handing it out, run `git -C path merge --ff-only michael/dev` to bring it current (on failure, mark it bad and use or prepare another). It records `taken_by` as the MCP caller (`ctx.caller`, the handler's second argument) or "unknown". It then prepares the next ready slot in the background, if the total is under K = 3. If none is ready and there is room, it prepares one and waits (worktree-up takes ~20 s); the tool description says so. If at K with none ready, it returns an error naming who holds each.
   - `return_worktree({id})`: if the worktree is clean and its branch is an ancestor of michael/dev (unused, or already merged), run `git merge --ff-only michael/dev` in it and mark it ready (idle_since now). Dirty, or holding unmerged commits: refuse with a clear message listing the files or commits. Never discard. If more than one is now ready, remove the extra (worktree-down).
   - Cleanup, every 10 minutes and at start: keep at most K = 3; remove any ready slot idle for more than N = 6 hours, beyond the one kept ready. Taken slots are never removed automatically.
   - Only one worktree-up runs at a time (a promise chain).
   - `GET /api/worktrees` (with cors, like `/api/system`) answers exactly `{ K, N_hours, slots: [{id, state, url, path, branch, taken_by, taken_at, idle_since}] }`. The Live card minion reads this shape.
   - `SERVEX_NO_POOL=1` turns it all off.
