## Yes, anything can go on a card

This box is a markdown file placed on the card. Any file in the card's folder can be drawn here.

| what | how |
|---|---|
| words, tables, checklists | an `.md` file in the card's folder, then a `{"place": "about.md"}` line |
| a note | a `{"message": …}` line |
| a live widget (a decision, a question, a quote: below) | a `place` line naming a `.js` view |
