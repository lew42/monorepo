## Deliverables

1. **`Servex/agents/claims.js`**: `export class Claims` built with `{ agents, file }` (file default `%LOCALAPPDATA%/lew42/servex/claims.json`). A claim is `{topic, agent, card, at}`, keyed by a slug of `topic`. `claim({topic, agent, card})` → `{ok}` or `{ok: false, holder, card, why}` when a DIFFERENT agent holds it and that agent is live and not stopped (a claim whose holder is gone or stopped is stale and is taken over). `release({topic, agent})`, `release_all(agent)`, `list()` (stale claims marked `stale: true`). Tools: `claim_topic({topic, card})`, `release_topic({topic})`, `list_claims()`; the agent is always `ctx.caller`, and a null caller is `"owner"`. A refusal's `why`: "<topic> is already being worked on by <holder> on card <card>. Ask mastermind-servex before starting."
2. **`Servex/agents/brief.js`**: `export function brief(servex)` returns the one-screen global brief as a string, at most 25 lines: a heading line, "Being worked on:" and one line per live claim (`- <topic>: <agent> on <card>`), "Running now:" and one line per live non-stopped agent that is not a minion, fork or job (`- <id>: <state>`, at most 12), and "Today's focus:" plus the `text` of the newest entry with `type: "focus"` in the `servex` log (use `servex.log.tail("servex", 300)`; since that is async, keep the last focus in memory: export `remember_focus(text)` and have Global set it at boot and whenever the mastermind writes one). No model calls. It must never throw: on any error it returns what it has.
3. **`Servex/agents/Global.js`**: `export default class Global`, house style, built with `{ servex }`, `install()` returns this. It:
   - builds `servex.claims = new Claims({agents})` and registers its three tools, plus `set_focus({text})` (appends `{type: "focus", by: caller, text}` to the `servex` log and calls `remember_focus`).
   - sets `servex.agents.policy.onrefuse = e => servex.log.append("policy", e)` when a policy exists, and adds `GET /api/policy` on `servex.dashboard.router` returning `{rules, refused}` (CORS like `Assistant.js`'s `route()`).
   - **The master assistant**, id exactly `master-assistant` (pass `id` explicitly): tier `fast`, effort `medium`, `permission_mode: "bypassPermissions"`, `system` = `master-assistant.md` + "\n\n" + `brief(servex)`, `allowed_tools`: `mcp__servex__card_reply`, `mcp__servex__send_to_agent`, `mcp__servex__list_claims`. Started at `install()` unless `SERVEX_NO_ASSISTANT` is set. It hears, through `servex.cards.on`, every fresh owner prompt on any card (`"card <id>: <text>"`) and every `message` line whose `kind` is `task`, `landed`, `blocked` or `error` (`"card <id>, <kind> from <by>: <text>"`), sent with `from: "owner"` for prompts and `from: "servex"` for the rest.
