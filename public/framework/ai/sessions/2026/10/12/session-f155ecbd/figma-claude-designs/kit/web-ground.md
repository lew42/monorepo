# web Ground scheme and phone sheet: done and merged (2026-10-12)

## ✅ Near-black ground `ext/Figma/tokens/`
- `.fig-near-black` is generated by `FigmaTokens.mjs` (`FigmaTokens.derived`): Dark BG's ink and accent over the dark ground mixed 50% with black. Opt-in, like the other schemes.
- Dark-only rules (lift, select trigger, media box, bands) now also apply to it.
- Demo: [/framework/ext/Figma/tokens/](/framework/ext/Figma/tokens/) shows it beside White, Light gray and Dark, with the contrast note: muted text is 4.0:1 on plain dark (fails 4.5) and 7.3:1 on near-black; primary is 13:1.

## ✅ Phone sheet for `.fig-select`
- Under 600 px of screen width the open panel is a bottom sheet over a 40% scrim. Pure CSS in `tokens.css`, plus one line in `FigSelect.js` (tapping the scrim closes it).
- **Not `ux/Popover`:** it anchors a JS-built box to a trigger; the select is native `<details>`, so using it would mean rebuilding the markup.
- Limits (in `doc/controls.md`): triggered by screen width, not `.fig-mobile`; does not work inside `.fig-lay` (container-type traps `position: fixed`).
