# Sign-in demo: what was asked

The ask is [brief.md](brief.md): the cloud chat's relay of the owner's words. It describes a video landing page at `/join/` with one button (Continue with Google, then Allow one notification a week, then done), plus settings, an in-app browser card, `?debug=1`, and web push with a weekly cron, deployed to staging only.

- **How it was split:** [plan.md](plan.md), which has the decisions and the API contract.
- **The three briefs:**
  - [api/requirements.md](api/requirements.md): the Worker routes, push and the staging deploy;
  - [join/requirements.md](join/requirements.md): the `/join/` page;
  - [fix/requirements.md](fix/requirements.md): the first review's findings.
- **Reviews:** [review.md](review.md), the latest one. The log of every step is [task.jsonl](task.jsonl).
- **For the owner:** [checklist.md](checklist.md), which gives each tap on the phone and what each screen says.
