1. **One mastermind per voice session, held truly open with no prompt.** `Sessions.js:ensure_mastermind(s)` spawns a standing `mastermind` (role `mastermind`, path `public/framework/ux/Dictate/`, model `claude-sonnet-5-5`, effort `high`, `dormant_after: 0`, `parent: "sessions"`, `parent_session: s.id`) the first time the single seat wakes, with **no `prompt`** — review finding 1 caught that round 1's `prompt: this.mastermind_brief(s)` ran a real Sonnet-high turn on the owner's very first sentence. Reworded (not added to) so the hand-off message itself also names the session id — the generic mastermind brief has no other way to learn it on a plain message hand-off (a `spawn_agent task: {from, id}` hand-off already carries it structurally). Brief is 892 words, under 900.
4. **Tests:** `Sessions.mastermind.test.mjs` now asserts the mastermind spawn spec carries no `prompt` key at all (review finding 1), alongside the existing checks (one spawn per session, reused not respawned, the seat brief carries the id with no leftover `{{`, failed-spawn fallback, brief under 900 words).
