## Does anything already map a prompt to the modules it names?

**Yes, partially: `ext/Refine`'s `RefinedCard` (brief v3).** Every refined ask already carries a `target` field — a mention (`/path` or `#Class`) naming what the ask concerns — set by the Haiku refine call and stored as `module`/`key` on the parsed ask (`public/framework/ext/Refine/RefinedCard.js:65,86,106-107`). This runs live, once per prompt, for VS Code tabs. It is the closest existing thing to "which module does this prompt mention" — but it tags the ask's **subject**, one target per ask item, not every `@`/`#` name literally written in the prompt text, and it has no reverse index (a module → its prompts) built from it yet; `--repeats` only groups by the target to find repeats, it doesn't render a per-module list. The 2026-10-12 asks-by-module effort did something closer to a reverse index (module → its asks) but only for two modules, as a one-off, not live.
