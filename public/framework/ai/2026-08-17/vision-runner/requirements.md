# vision-runner — `ext/DesignTool/vision/run.mjs` + `prompts/`

Laws: less is more · clarity · prioritize. **Deliverable: a runner that produces a real pilot run Mike can browse; final message ≤ 25 lines. Reuse before writing.**

Spec: [`../screenshot-tool/requirements.md`](../screenshot-tool/requirements.md) §Design — the record schema there is **fixed** (a sibling agent builds the browse page against it in parallel). Evidence: [`../shots-history/proposal.md`](../shots-history/proposal.md) §4–5 (mechanics that work, costs measured, traps).

## Build

1. `public/framework/ext/DesignTool/vision/run.mjs` — Node ESM, `node run.mjs --pages ... --widths 390,1280,3440 --regions auto --prompt critique-full-v1 --model sonnet --out public/framework/ai/2026-08-17/vision-pilot`. Reuse `Server/plugins/Shot.js`'s playwright settings and `Server/plugins/Ask.js`'s `claude -p` invocation (import them if their shape allows; otherwise copy the ten lines and say so). Fresh session per image (`--session-id <uuid>`, never `--resume`); `--allowedTools Read`; parse `--output-format json` for `session_id`, `usage`, `total_cost_usd`. Whole page first, then `locator.screenshot()` per region from `probe.js`'s node walk (≤8 per page-width, min 120×80, no nested regions), each region line carrying `page_shot`. Concurrency 3 asks at once; write `vision.jsonl` **as you go** (a crash keeps what was done); `--dry` prints the plan and cost estimate without asking; `--resume-run` skips shots whose hash is already in `vision.jsonl`. Also `--turn2 css-v1`: resume the *same* image's session once with the css prompt + the region's DOM outline (tag + classes, 2 levels, from probe.js) → `findings[].decl`; log its tokens separately as `turn2`.
2. `public/framework/ext/DesignTool/vision/prompts/critique-v1.md`, `critique-full-v1.md`, `css-v1.md` — write them from the three prompts quoted in shots-history §2 (P1's *"Judge ONLY what you can see in each image"* discipline, P2's brevity). Prose first, several angles (layout · spacing · hierarchy · contrast · alignment · empty space · missing backgrounds · UI/UX · imagery), then a fenced JSON block `[{"class":"broken|maybe","what","where"}]`. **No numeric score.** ≤ 40 lines each. Runner writes `prompts.json` (id → text) into the run dir.
3. **Run the pilot**: pages `/framework/`, `/framework/ai/`, `/framework/ai/2026-08-17/`, `/framework/ext/DesignTool/`, `/framework/ui/`, `/framework/web/` (substitute a live sibling if one 404s — log it) × 390/1280/3440, Sonnet, `critique-full-v1`, `--out public/framework/ai/2026-08-17/vision-pilot` (create that task dir with a one-line `task.jsonl` assign + `requirements.md` saying "pilot run of vision-runner"). Then the **12 page-shots** (1280 + 3440, all six pages) again with `--model opus`, and **3** (1280, three pages) with `--model fable` if the CLI accepts it (else log that it doesn't) — same prompt, so the browse page can compare. Log the totals: shots, $ per model, tokens per model.
4. `ext/DesignTool/vision/readme.md` (≤ 20 lines: what · run it · watch out · more) and one line in `ext/DesignTool/readme.md` pointing at it. Run `documentation`.

## Rules

- Files: `ext/DesignTool/vision/{run.mjs,prompts/,readme.md,prompts.json}`, one line in `ext/DesignTool/readme.md`, this dir, and the `vision-pilot` task dir (its `shots/` is gitignored — verify with `git check-ignore`). **Not** `page.js`/`browse.js`/`vision.css` in that dir (sibling agent). Never Mike's live tabs; `BLOCKRELOAD=true` on the headless side.
- Skills: `code` once; `documentation`; `finish-task` to land. Log milestones in `task.jsonl` here (bash `printf`, never Out-File); bump `step`.
- Land with: the run's `vision.jsonl` line count, $ per model, the three prompt paths, and one decisive spot-check (open one region png and its prose side by side — does the prose describe *that* image?).
