# Move the forgettable steps from skills into node

**Source:** the system audit card 2026/09/29/system-audit-skills-tools-handover-loose and its reports in `ai/2026-09-29/servex-mastermind/audit/`. The finding: every step an AI must remember is skipped often, and every step node does, happens.

## Deliverables, in order (each is its own small commit, and each keeps the old path working)
1. **One skill log.** The Skill hook writes every call through Servex `append_log` to a single `skills` log: `{at, session_id, agent_id, skill}`. It no longer needs a task.jsonl to walk up to. Add a `skills_report` tool that counts calls per skill and per agent for a date range.
2. **A `land` tool** (in-process SDK plus a CLI). It writes `landed_at` and the outcome only into the caller's OWN task dir, resolved from its session id in the registry, and refuses any other path. It runs layout-check, padding-check and text-check first and puts their results on the landing line. It never blocks on a finding; it records it. finish-task calls it.
3. **The reload hold needs its paths.** `hold.mjs on` without `--paths` is refused, with a one-line reason.
4. **A dispatch queue.** Today's dispatch table (`ai/2026-09-25/servex-mastermind/dispatch.md`) left 6 rows unlaunched for hours. Replace it with Servex `dispatch.jsonl`: `{row, role, name, model, effort, brief, card, after:[names], resume_session?}`. Servex launches the next ready row whenever fewer than 8 agents are working and more than 4 GB is free. A row is ready when every name in `after` has landed. It logs each launch, and a `dispatch_status` tool shows the queue. Keep `pause_dispatch` working. Seed it from dispatch.md's open rows.
5. **Checkpoint by context.** The heartbeat sends a mastermind-role agent "write checkpoint-N now: decided, running, ready, pending, lessons" when its `context` passes 150k, once per 50k after that. A fresh Servex mastermind's first prompt is `first_prompt(dir, [the latest checkpoint, the last 15 task.jsonl lines, open cards])`.

Proof for each: one command and its output, in the task dir. Land with merge.mjs. Don't restart Servex from your shell: ask mastermind-servex-7, unless restart-outside-tree has landed. Model: Opus, medium. Fence: .claude/hooks/*skill*, Server/land.mjs (new), .claude/skills/finish-task/SKILL.md (one line), Server/hold.mjs, Servex/agents/Dispatch*.js (new) + its registration, Servex/Heartbeat.js (the checkpoint part).
