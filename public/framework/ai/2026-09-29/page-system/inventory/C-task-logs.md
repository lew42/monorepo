## Five biggest finds

1. **page.jsonl has no monitor or purge — 480 files, largest 257 KB — and it's already causing shared-worktree commit collisions** (today's page-system log, decide-tool, task-loop, chip-context-fix, layout-explorer, readme-chain). This is the one item the owner explicitly asked about and it is a live, open problem.
2. **The owner has already ruled on "swapping vs switching" navigation**: two named categories, "stable" (nothing you're reading moves) vs "dynamic", with 4 proven-0px demos and a shipped core fix (open columns freeze width instead of resizing) — reuse this vocabulary and mechanism, don't re-derive it.
3. **Columns are already a shipped core page shape** (`page.columns()`, width words, breadcrumbs, `.bleed` for flush) plus a **page generator** that builds real navigable trees from a DSL — this is most of "any templates, any previews" already built.
4. **Make (`/imagine/paging/make/`) is a working three-pane page CMS** with drag-and-drop reorder/nesting and a live (not screenshot) middle pane — the closest existing thing to a page-builder preview system.
5. **A persistent-sidebar + swapping-centre pattern already exists and works** (`/imagine/paging/rightnav/`) but was never wired into its own hub's `children:` — it's reachable only by direct url, a one-line fix someone should do.
