The simplest possible demo: one `Page`, no children, one line of prose. First in
the rail on purpose — "a page is a `title` and some `content()`" is the whole
lesson, and the tree (`hello`) is four lines.

## What it establishes for every demo after it

That the url derives (`Hello` → `/hello/`, via `Page.slug`) and that nothing here
is on disk — the object's existence *is* the route. Every one of the other
thirteen demos assumes the reader already believes this.
