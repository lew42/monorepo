and one call — `content(){ this.previews() }` — with the `--column`/`--gap`
retune written inline as the demo's only real content. "Drag the handle" (the
stage's resize handle) is the interaction the whole page exists to invite.

## What it establishes for the four arrangement demos after it

That `previews()` is the baseline every other arrangement (`catalog`, `dashboard`,
`strip`) is a variation *of* — same nine children reused in spirit across the
group, so the reader's attention stays on what changed (a rail instead of a wall,
unequal card sizes, a scrolling row) rather than re-learning the base case each
time.
