# The page tool: any agent changes any page by path + delta (owner, 2026-10-09 ~18:05)

Dictated in VS Code tab 7efd07d5. Shared by the page system and the AI system (linked from both readmes).

## The owner's ask
- Any agent (a voice session, a mastermind, a minion) can change **anything about a page** (content, layout, tabs, navigation) while the owner watches: "create a new tab on this page" and the tab appears instantly.
- The mechanism: **a path + a delta**. The page's `page.jsonl` deltas (a plain nested object is a `set`, a verb key calls a method) are the universal language; one tool writes them. The agent supplies only the path and the raw JSON delta; **never the timestamp or ids**: the tool stamps those.
- **The path comes from context**: in a voice or VS Code session, "this page" is the session's own page; the agent decides when another path is meant.
- **Every session gets a `page.jsonl` beside its `session.jsonl`.** The default session view (the template, `ai/AISession/AISessionDetail.js`) renders it; the page.jsonl can then reshape that page entirely. Each session should have a **name** (its slug); VS Code sessions do not have one yet.

## What already exists (verified 2026-10-09)
`Servex/agents/page_tools.js`: `page_call(path, target, verb, args)` (the general tool: one verb at one target), `page_set` (a plain delta = set), `page_add` (one content item; stamps id, `by`, `ts`), `page_read` (current state computed from the log). So the tool is largely built; the gaps are below.

## Status (2026-10-09, evening): the four gaps are closed
Built and shown live, no reload: a delta adds a tab, changes a layout word or the navigation; a session page is reshaped by its folder's `page.jsonl`; every agent is told its own page; the tool stamps `by`/`ts`/ids and resolves the route path. Classes and decisions: [architecture.md](architecture.md). What is still open is listed there under "Open".

## Gaps to close (the page mastermind's job)

4. One demo: the owner says "add a tab here" in a session, and it appears with no reload.
