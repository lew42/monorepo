# `readme.md`

The design record for this tier: the council's three independent proposals
(`agents/steve/`, `agents/eric/`, `agents/tim/`) and where the shipped design
agreed or dissented from each; three real bugs the review round caught and
fixed (the captor, an unguarded `activate()`, `error()` emptying the chrome);
and nine numbered "Open" items naming exactly what the Router tier has to add.

## Structure worth knowing

A table (`## The council's decisions`) is the spine — one row per decision,
verdict plus dissent — followed by three prose sections for what review caught,
then `## Open, and what the Router changes`, ranked. This is the shape every
tier's readme in `core/new/` follows.
