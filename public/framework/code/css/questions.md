# CSS — review questions

The css skill's old `questions.md` had two sections, "Spacing and padding" and "Colour and
contrast" — both moved to [/framework/design/layout/](/framework/design/layout/) and
[/framework/design/color/](/framework/design/color/) respectively (spacing is a layout fact,
colour is a design fact; this page answers "where does the CSS rule go", not "how much space" or
"what colour"). Nothing else was in the old file, so there is nothing left to move here yet.

A question that is really about layers, declaration placement or class naming belongs here when
one is written. Until then, `review` finds this system's checks on
[patterns](/framework/code/patterns/)'s and this page's own rules — read, not scored yet.
