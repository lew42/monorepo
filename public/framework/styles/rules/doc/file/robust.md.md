## What this file is

The fourth chapter: seven CSS blocks proven to hold from 400px to 3440px with
no media query, plus the one arrangement (sidebar-and-body) where a media
query is the right tool. Each of the sixteen `layouts/` pages is an instance
of one or more of these seven.

## Explicitly a shortlist, not a survey

The file's own "Open" section says so — this is what has been proven, not an
exhaustive catalog. Worth reading alongside `layouts/readme.md`'s own
inventory of which layout teaches which pattern; the two lists overlap by
design but were never meant to be merged.
