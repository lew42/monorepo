## What this file is

The fifth chapter: before defining a new block, run the census
(`rg` for existing classes), ask three questions (does something already do
this, is the difference a value or a vocabulary, will there be a third), and
know the five-block demo system by heart.

## Where it earns its place

This is the only one of the five chapters that is procedural rather than
descriptive — it is a checklist to run *before* writing CSS, not a fact about
CSS. It is also the chapter every other module's readme in this framework
implicitly assumes the reader has internalized (the "one demo system, five
blocks" line is quoted verbatim in `CLAUDE.md`).
