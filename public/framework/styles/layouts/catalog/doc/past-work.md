# Past work: what the catalog builds on

Run `node Server/PastWork.mjs layout catalog colour schemes` on 2026-10-12. Nothing already ranked the layouts against content, so the catalog is new; everything it shows is reused.

- **Reused, still live:** [core/Layout](/framework/core/Layout/) (30 layouts, 33 importers), [styles/layouts](/framework/styles/layouts/) demos, [ext/catalog](/framework/ext/catalog/), the layout map at `ai/sessions/2026/09/30/page-audit/page-audit/layout-map/`, and the colour work in `color-lighten-darken` (2026-09-17) and `color-study` (2026-09-01).
- **Different:** those list or measure layouts; this catalog adds use counts (`census.mjs`), a score with a reason, and a content-to-layout guide ([matching.md](matching.md)).
- **Colour rule:** [colour-schemes.md](/framework/styles/doc/colour-schemes.md) extends the earlier colour studies, it does not replace them.
