# cols.css

The proposal in code. One rule computes every track and six words set two numbers on the
container and one on each child. `doc/words.md` is the argument; the sheet itself carries
the four decisions inline (percentage basis, grow-by-weight, `rem` floor / `em` rail, and
the `max()` stack term instead of a container query).

Below the words is the lab's own presentation — `.cols-cell`, `.cols-px`, `.cols-read`,
`.cols-screen` — which is not part of what would be promoted.

`cols-` is reserved in `styles/css-scopes.txt`. Not the bare `.cols`:
`core/new/1/site/styles.css` already defines one.
