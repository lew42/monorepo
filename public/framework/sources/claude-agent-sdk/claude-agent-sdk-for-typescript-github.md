# Claude Agent SDK for TypeScript

Official TypeScript/Node.js SDK for Claude Agent, enabling you to programmatically build AI agents with Claude's capabilities.

## Installation

```bash
npm install @anthropic-ai/claude-agent-sdk
```

## Requirements
- **Node.js 18+**

## What You Can Do

The SDK enables autonomous agents that can:
- Understand codebases
- Edit files
- Run commands
- Execute complex workflows
