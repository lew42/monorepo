# Crush (formerly OpenCode): Terminal AI Coding Agent Review

OpenCode was rebranded as Crush after its creator joined the Charm team in summer 2025. Crush CLI is the direct successor to OpenCode, built on the original Go codebase with continued development and acceleration.

## Evolution from OpenCode to Crush

The transition involved the project's creator being hired by Charm, a renowned terminal UI team. Crush continues the Go-based implementation of OpenCode while receiving active maintenance and feature development through the Charm organization.

## Crush as an AI Coding Agent

Crush is a Go-based open source CLI application that brings AI assistance to your terminal and provides a terminal user interface (TUI) for interacting with various AI models to help with coding tasks, debugging and more.
