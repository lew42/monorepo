# Crush: Glamourous Agentic Coding

**Status:** Crush is the continuation of the archived OpenCode Go project (which was archived September 18, 2025) and is actively maintained by Charm Bracelet.

**What It Is:**
Crush is a glamourous AI coding agent for the terminal, built on the foundation of the original OpenCode project. It provides intelligent coding assistance, agentic capabilities, and multi-model support.

**Key Capabilities:**
- Terminal-based AI assistant for developers
- Multiple AI provider support (OpenAI, Claude, Gemini, AWS Bedrock, and others)
- Session management for saving conversations
- Tool integration allowing the AI to execute commands and modify code
- Language Server Protocol (LSP) support for code intelligence
- Model Context Protocol (MCP) for extending functionality through external integrations

**Note:** The original OpenCode repository (github.com/opencode-ai/opencode) is now archived. Users are directed to follow Crush for ongoing development and updates.
