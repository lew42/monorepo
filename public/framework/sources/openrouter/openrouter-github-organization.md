# OpenRouter: Project Overview

## Core Mission
OpenRouter provides a unified API interface to access 400+ language models from multiple providers (OpenAI, Anthropic, Google, Meta, Mistral, etc.) through a single, OpenAI-compatible endpoint.

## Key SDKs & Tools

**Official Client Libraries:**
- **TypeScript SDK** (`@openrouter/sdk`) - Type-safe access across runtimes
- **Python SDK** - Sync and async clients with Pydantic types
- **Go SDK** - Includes provider routing and guardrails

**Agent Framework:**
- **TypeScript Agent** (`@openrouter/agent`) - Handles tool orchestration and multi-turn conversations with automatic execution

**Integration Tools:**
- Vercel AI SDK provider
- Terraform provider for infrastructure-as-code management
- Benchmark harness for reproducible LLM evaluations

## Main Advantages

The platform emphasizes: "One API, 400+ models" across 90+ providers, with automatic fallbacks, price/performance routing, and "no lock-in" flexibility. Developers can switch models instantly while maintaining consistent code structure.
