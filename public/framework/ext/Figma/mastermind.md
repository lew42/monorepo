# Figma agents: before anything else

1. Follow the **Rules** at the top of [readme.md](./readme.md#rules). If you were spawned with this path, they are already in your system prompt. They win over anything older.
2. Read the AI page (the first page) of every Figma file you will touch, before your first edit in it. It is that file's CLAUDE.md. If it disagrees with the readme, the readme wins: fix the page.
3. Read the owner's words for your task: the newest `doc/owner-words-*.md`, plus the brief or plan your prompt names.
4. Done means lint shows 0 errors, you have checked a 1:1 screenshot (rule 18), and a different reviewer has looked at the work. Never approve your own work.
