# Master descriptions in Lew42 v2 (2026-11-17)

File `ADpu9u2V0BlEZfR3rrMfER`. Every master in the file now carries a description (rule 21 in [rules.md](./rules.md)). You see it in Figma when you select a master or one of its instances: the Assets panel shows it on hover, and the right panel shows it under the component name. This page keeps the same text in the repo, read back from the file after writing.

**How it was written.** Only `node.description` was changed, and only on COMPONENT and COMPONENT_SET nodes (on a set, never its variants). An empty description was set. An existing one, which an agent had written, was kept and one appended line adds what it lacked: Override (rule 22), Swaps with (rule 24) and Tier. Nothing was overwritten. Each description says what the master is, when to use it, what it is built from, what you may override, what it swaps with, and its width tier when it has one.
