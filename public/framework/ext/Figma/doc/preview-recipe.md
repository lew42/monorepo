# Preview recipe: one `.<Page> Preview` per page (Lew42 v2, 2026-11-16)

Built and checked on `.1000 Default Preview` 162:10434 and `.400 Mobile Preview` 162:10582 (both lint 0). Layout rules come from [study-space.md](./study-space.md) section 3; the check is [lint.md](./lint.md).

1. **Sheet.** A COMPONENT named `.<Page> Preview`, the first child of the page's `Root` (`root.insertChild(0, comp)`; never move or delete the page's own content). Vertical auto layout, 1920 wide, Hug height, counter-axis centre, padding left/right 0, top/bottom bound to Scale `pad-y`, gap bound to `gap`, fill bound to Colors `light`. Set explicit Scale mode **1000 Default** and explicit Scheme mode **White** on the sheet, or white cards read as the ground.
2. **Content (1600).** One Fixed 1600 frame in the sheet. Its children, in order: `Header` (Title as h1 text style with a NODE hyperlink to the page id, plus one `Line` of body text with Hug width, so it stays under the 720 measure), an optional `Band`, then `Columns`.
3. **Columns.** One horizontal frame, Fill width, Hug height (`counterAxisSizingMode = 'AUTO'`), gap bound to `gap`, holding 3 vertical Fill columns (512 each). 6 to 9 distinct instances, three per column. Balance by brute force: assign items to columns so (tallest minus shortest) is 10% or less of the tallest. Never stretch a card.
4. **Instances only, real copy.** Create each with `component.createInstance()`, append it, then set Fill width. Override text with `loadFontAsync` then `characters`; write real short copy, nothing repeated on the page, no placeholder lines, no Note or Specimen instances (they are doc tools). Photo cards use an image fill (hash of the seagull image in the file). Masters are never edited.
5. **Hug, not clip.** Nested layout instances (Three cards, Nav + main, Two small cards) hold Fill/Fill children; set the inner Cards and Regions to Hug height or the last line clips. A Horizontal frame needs `counterAxisSizingMode = 'AUTO'` to hug. Append children first, then set Fill; `resize()` resets sizing. Read a height one call after the change, never in the same call.
6. **Nested mode.** A nested instance inherits the sheet's mode. For one built for another tier (a 360 screen, a 600 layout) call `setExplicitVariableModeForCollection(scale, modeId)` on it, which works on nested instances. Phone screens keep their native padding.
7. **Wrapper.** A section-like master (Stat tiles, List section, Icon + title) is wrapped in a vertical frame: fill bound to Scheme `fill`, padding bound to `pad-x` / `pad-y`, radius bound to `radius`, effects copied from `Card`. No bare section on the ground.
8. **Wide pages (Desktop, Mega).** One band at the top: the page master at its native width inside a Fixed 1600 frame, scaled down with `rescale()`; shape only.
9. **Check.** Paste `lint.js` with `return await lint(['<preview id>'])`: 0 errors (the sheet's own mode-mismatch warning is expected). `get_screenshot` on the preview id, download with `curl -sf -L`, and read it at 1:1: no clipped text, no void, nothing floating.
9b. **Builder shortcuts.** Clone the finished `.1000 Default Preview` (`tpl.clone()` gives a component), keep only `Header` in `Content (1600)`, set Title and Line (Line fixed at 700 wide so it does not leave one orphan word), then `setRangeHyperlink` on the Title with `{type:'NODE', value:<page id>}`. Clone the template `Columns` frame, empty it, and `root.insertChild(0, sheet)` works across pages. Wrapper = clone of the `Stat card` wrapper with its children removed. Photo cards copy `fills` from the seagull rectangle `I164:263;16:375`. Balance with a 3^n brute force in a second call (heights are only valid one call after the change).
9c. **Scaled masters.** `instance.rescale(0.49)` works on instances and keeps the explicit Scale mode: 1600-wide templates become 784 and sit two to a row; set the row's height and clip it to cut empty space under a short master (Rail + Main + Rail). A master with its own `#f5f5f5` fill sits on a white row (fill bound to Scheme `fill`), or lint reports same-on-same.
9d. **A page with no components** (Text) gets wrapper cards of styled text (one per text style, real copy) instead of instances; say so in the report.
9e. **Tool limit.** The Figma MCP seat (Pro, Full) allows about 10 calls per minute, shared by `use_figma` and `get_screenshot`. A rate-limit error clears after about 90 seconds (wait, then resend the identical call); it stopped the rollout twice on 2026-11-16 and both times the retry worked. Each preview needs about 3 calls: build, balance + lint (one call), screenshot.
9g. **Same fill on same fill.** A master that carries its own `#f5f5f5` fill (Stat card, Button) goes in a white wrapper (a clone of the wrapper template with its children removed). A master with its own white fill is not wrapped. `Layout.Sidebar` State=Open has same-on-same inside, so it cannot serve as a band.
9h. **Band.** A Mega or Desktop band is the Res set's Card variant in the page's own mode, `rescale(1600 / width)`; it renders as an empty card with a mode label, which is accepted. A tier with no band (XL, LG, SM, XS) removes everything but `Header` from `Content`.
9f. **Existing hand-made content.** Insert only the Preview at index 0 of the Root; never move, wrap or restyle an existing node (Desktop has hand-built items). Desktop's specimens (`Specimens · 1920 Desktop` 128:8860) list what the page uses: Card, Button, Icon.Item Set, 1920 Page, Rail + two cards, Three cards, Res.1920 Desktop Set, Content area; use them as the instance list. Mega's (128:9175): Card, Button, Icon.Item Set, 2600 Sidebar + Main, Main + Aside, Three cards, Res.3440 Mega Set, Main + aside + card.
10. **Index.** Index's Root has 3 columns (Foundations, Components, Sizes), each a caps header and one line, previews stacked 120 apart as instances of these components; each preview's Title links to its page.
