# Controls: Toggle, Checkbox, Radio, Select, Icon (2026-10-12)

Coded from the Figma pages `DS · 2.7 Toggles, checkboxes & radios`, `DS · 2.6 Dropdowns & menus` and `DS · 1.1 Icons`. Opt-in like the buttons: they live in [`../tokens/tokens.css`](../tokens/tokens.css), generated by `FigmaTokens.mjs` (the `controls` list), shown on [/framework/ext/Figma/tokens/](/framework/ext/Figma/tokens/). Nothing global changes; every class is `.fig-*`, inside the `theme` layer.

| Class | Markup | Notes |
|---|---|---|
| `.fig-toggle` | `<div class="fig-toggle"><span>Label</span><input type=checkbox></div>` | switch sits right; on = accent, knob on-accent |
| `.fig-check` | `<div class="fig-check"><input type=checkbox><span>Label</span></div>` | `indeterminate` shows a dash |
| `.fig-radio` | same with `type=radio` | |
| `.fig-select` | `<details class="fig-select"><summary><span>Value</span></summary><div class="fig-select-panel"><div class="fig-select-row" aria-selected=true>…</div></div></details>` | panel under the trigger, max 264 tall, scrolls |
| `.fig-icon` + `.fig-icon-16/20/24/32/48` | `<span class="fig-icon fig-icon-24">settings</span>` | Material Symbols Rounded, falls back to Material Icons (the site's font); `.fig-icon-fill` |

Shared: 44 px minimum height, off = 15% of the text ink (works on all three schemes), focus = 2 px accent outline, offset 2, disabled = 40% opacity (`<input disabled>`).

Watch out: the page must load the Symbols font itself (the demo adds a `<link>`); without it icons fall back to Material Icons, which has the same names for the common glyphs. `.fig-select` does not close on outside click or choose a row yet: it is the styling, wire behavior with `ux/Menu` / `ux/Popover`.
