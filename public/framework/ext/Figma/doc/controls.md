# Controls: Toggle, Checkbox, Radio, Select, Icon (2026-10-12)

Coded from the Figma pages `DS · 2.7 Toggles, checkboxes & radios`, `DS · 2.6 Dropdowns & menus` and `DS · 1.1 Icons`. Opt-in like the buttons: they live in [`../tokens/tokens.css`](../tokens/tokens.css), generated by `FigmaTokens.mjs` (the `controls` list), shown on [/framework/ext/Figma/tokens/](/framework/ext/Figma/tokens/). Nothing global changes; every class is `.fig-*`, inside the `theme` layer.

| Class | Markup | Notes |
|---|---|---|
| `.fig-toggle` | `<div class="fig-toggle"><span>Label</span><input type=checkbox></div>` | switch sits right; on = accent, knob on-accent |
| `.fig-check` | `<div class="fig-check"><input type=checkbox><span>Label</span></div>` | `indeterminate` shows a dash |
| `.fig-radio` | same with `type=radio` | |
| `.fig-select` | `<details class="fig-select"><summary><span>Value</span></summary><div class="fig-select-panel"><div class="fig-select-row" aria-selected=true>…</div></div></details>` | panel under the trigger, max 264 tall, scrolls |
| `.fig-icon` + `.fig-icon-16/20/24/32/48` | `<span class="fig-icon fig-icon-24">settings</span>` | Material Symbols Rounded, falls back to Material Icons (the site's font); `.fig-icon-fill` |

Shared: 44 px minimum height, off = 15% of the text ink (works on all three schemes), focus = 2 px accent outline, offset 2, disabled = 40% opacity (`<input disabled>`).

Watch out: the page must load the Symbols font itself (the demo adds a `<link>`); without it icons fall back to Material Icons, which has the same names for the common glyphs. `.fig-select` behaves via `FigSelect.install()` (`tokens/FigSelect.js`): a row click sets the trigger text, marks `aria-selected`, closes and fires a bubbling `fig-select` event (`detail.value`); outside click and Escape close; Arrow keys move, Enter picks; one open at a time when you open one (a page may start with several open, as the tokens demo does), and the chosen row scrolls into view inside the panel, never the page. It reuses `ux/Menu`'s native-`<details>` recipe but with delegated listeners, so plain markup works with no per-instance setup. **Phone sheet (DS 2.6 C):** under 600 px of screen width the open panel is a bottom sheet over a 40% scrim, pure CSS in `tokens.css` plus one line in `FigSelect.js` (a tap on the scrim, which is the `<details>` itself, closes it). Not `ux/Popover`: that anchors a JS-built box to a trigger, and the select is native `<details>` with delegated listeners, so adopting it would mean rebuilding the markup. The sheet is by screen width, not the `.fig-mobile` class, and does not work inside a `.fig-lay` (its container-type traps `position: fixed`). The 264 cap and scroll are CSS.
