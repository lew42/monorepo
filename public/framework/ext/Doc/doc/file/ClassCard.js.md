The class page's API tab body. `ClassCard extends View`: `new ClassCard({ doc })` draws the title card, the Core API block, the subject's own members, then one group per base class. `ClassCard.chain(doc)` is the prototype-chain walk, `ClassCard.weights(core)` reads the `core:` string, `ClassCard.registry` maps a class to its Doc. The rules are in [doc/class-card.md](../../class-card/).
