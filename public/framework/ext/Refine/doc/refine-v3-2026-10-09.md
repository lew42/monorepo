## What changed, and the numbers

| Step | Before | Now |
|---|---|---|
| Cleaned text visible | after the whole refine, about 64 s | `quick_clean()` in `engine.js`, no model, about 0.3 ms per chunk or keystroke |
| Refine (clean, outline, clarity) | one slow call chain, about 64 s | clean first, then outline and clarity in parallel: about 8 to 9 s on Sonnet 5.5 |
| Each model call | hidden | its own NEW session (`Servex/ext/refine/RefineCall.js`, Agent SDK, no tools or skills, thinking off, effort low), listed with model, time, cost and a link to `/framework/ai/sessions/<id>/` |
| Cost per refine | n/a | about $0.003 to $0.0075 per call when the prompt cache is warm; a cold cache made parallel same-model calls about $0.07 each (one cold run cost $0.57) |

## Haiku 5.5 vs Sonnet 5.5, low effort, thinking off

Measured with `RefineCall` on a 3-sentence clean (cold call first, then warm): Haiku 4.7 s / $0.077 cold, 3.0 s / $0.009 warm (331 to 519 output tokens); Sonnet 2.6 s / $0.068 cold, 2.6 s / $0.004 warm (57 to 65 output tokens). Sonnet was faster and cheaper warm, because it answers tersely. Haiku writes longer answers, so it is no cheaper here; it is still used for the per-sentence clarity calls, where it scores well and the price per call is tiny. The page's Model select switches the main clean and outline calls between them.

## Clarity: model vs the old Scorer

`ClarityScorer` (Haiku, one sentence at a time, with only the previous and next sentence) gives a score and a one-line reason per sentence. The old rule `Scorer.js` gave nearly every sentence the same number. The model scores spread from 0.55 to 0.8 on the test dictation and say why ("'it' refers to something not named"), so the model score is the one shown. The rule score is kept on each sentence as `rule_clarity`.

## Whisper as classes

`audio/Whisper` holds `Whisper` (server up or down, ping, restarts seen) and `WhisperSession` (one per dictation surface, logging every request: audio size, seconds, send frequency, reply, latency, revisions where an earlier word changed). Both have a `static View`. The hand-built log (`ux/Dictate/WhisperLog.js`) is left in place, unused by Refine. Not built: the server's model name (the server does not report it), and a replay timeline.
