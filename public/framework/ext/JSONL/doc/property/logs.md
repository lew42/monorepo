Every `{"log": …}` value, in file order, unmodified — `log()` is a bare `push`, so nothing merges and nothing is ever removed. `ext/Timeline`'s `ai.js` maps this straight into timeline dots (`l.at`, `l.msg`).

Starts `[]`, a class field — invisible to `Doc.declaration`'s source lookup, which is why this page has no source panel above. The prose here is the only record of the shape.
