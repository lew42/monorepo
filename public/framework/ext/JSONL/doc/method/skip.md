Called by `apply()` for any key not in `this.constructor.verbs`. Pushes the **whole entry** (not just the unknown value) onto `.skipped` and `console.warn`s — the design choice this class exists to make: an unrecognized verb stays visible instead of vanishing, because a `.jsonl` file is meant to be blindly appendable by an AI, and a silently-dropped typo is exactly the failure mode that invites.
