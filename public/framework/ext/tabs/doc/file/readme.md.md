The maintainer's document: why the component looks the way it does, what was
rejected (`.minimal`), and the traps that never throw. The reader's document is
`page.js` — blurring the two is the failure this split exists to prevent.

It is served twice: cited by a maintainer reading the directory, and collapsed at
the bottom of the Overview tab via `md.details(import.meta, "readme.md", …)`.
