The `javascript` grammar, vendored from the same highlight.js 11.11.1 release
as `core.min.js`. Standalone ESM, `export default hljsGrammar` — the two
occurrences of the string `"import"` inside are grammar keyword literals (for
highlighting the word `import` in someone else's code), not an actual ES
`import` statement; this file has none.

Registered under both `code.js` and `code.javascript` — see `doc/choice.md`
for why the accessor map keeps both spellings instead of relying on aliases.
