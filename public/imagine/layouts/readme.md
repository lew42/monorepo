# Layouts — moved

This realm used to number eighteen layouts (`2.golden`, `3.card`, …). Layouts now have **names, not numbers**, and they live in one place.

- The names, each one a live page: [/framework/core/Layout/](/framework/core/Layout/)
- The layout standard, drawn and judged: [/layouts/](/layouts/)
- The six shape labs moved to [/layouts/labs/](/layouts/labs/)

An old url such as `/imagine/layouts/2/golden/` still answers: it sends you to `/framework/core/Layout/golden/`. The record of why this realm existed is [doc/decisions.md](./doc/decisions.md).
